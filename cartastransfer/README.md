# Hablemos: cartas conversacionales

App web para jugar en familia con las cartas conversacionales de PlatFAMs, sin el mazo físico. Se abre en https://gustavoh13.github.io/Proyecto1/cartastransfer/ y se puede añadir a la pantalla de inicio del teléfono; después de la primera visita funciona sin conexión.

La app no guarda ni envía datos fuera del teléfono. Las tipografías y las imágenes están alojadas en esta misma carpeta.

## Para actualizarla

Reemplaza los archivos de esta carpeta y sube el número de versión en la línea `CACHE` de `sw.js`.
