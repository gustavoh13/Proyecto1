# Sessions ADC-PAU

App web de las cuatro sesiones del proyecto **Alfabetització Digital Crítica per a la Pau (ADC-PAU): Disseny i validació d'un marc pedagògic anti-(neo)feixista amb joves a Catalunya**.

Borrador de trabajo para la sesión de codiseño con el equipo y los educadores.

## Financiación

Institut Català Internacional per la Pau (ICIP), convocatoria R-ICIP 2026. Expediente ICI04426000003.

## Qué contiene

- `index.html`: la app completa (HTML, CSS y JavaScript en un solo archivo), en catalán y castellano.
- `img/`: logos de la Universitat de Barcelona y del ICIP.

Para abrirla basta con abrir `index.html` en un navegador. Carga dos tipografías desde Google Fonts; sin conexión usa las del sistema.

La app no guarda ni envía ningún dato y no contiene ejemplos reales de discurso de odio.
